# Workflow: Recriar Seção

Objetivo:

Recriar uma seção visual baseada em referência.

Regras:

1. Nunca copiar HTML.

2. Nunca utilizar scraping.

3. Identificar:

* Estrutura visual.
* Hierarquia.
* Espaçamentos.
* Componentes reutilizáveis.
* Animações.

4. Planejar a implementação.

5. Criar componentes.

6. Criar traduções.

7. Garantir responsividade.

8. Garantir acessibilidade.

9. Validar contra react-lp-rules.md.
