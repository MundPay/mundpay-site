# Workflow: Revisão Final

Antes de considerar uma tarefa concluída:

Verificar:

* Build funcionando.
* Typescript sem erros.
* Componentização correta.
* Semântica HTML.
* Acessibilidade.
* Traduções.
* Responsividade.
* Performance.
* Reutilização.

Checklist:

[ ] Sem any
[ ] Sem SVG espalhado
[ ] Sem useEffect desnecessário
[ ] Sem HTML copiado
[ ] Sem código morto
[ ] Sem componentes gigantes
[ ] Sem textos hardcoded
[ ] Sem classes arbitrárias desnecessárias

Gerar relatório final.

Não realizar novas alterações nesta etapa sem aprovação explícita.
